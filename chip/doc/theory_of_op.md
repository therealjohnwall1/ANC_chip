# Theory of Operation
Anchor interacts with an external microcontroller for bring up and initialization which includes tunining and defining s_taps
along with filling the MAC to allow for rolling multplications on the first iteration. the ANC logic will take in X[n] (external noise)
from a reference microphone(ADC + analog frontend) which will be abstracted/simulated in this implementation.
Then ANC block will then try to predict tap coefficents W(z) using gradient descent while using hard coded S(z) to also adjust/zero out
the noise.

The full chain of operations is shown below, basically the entire system this logic aims to represent.
![Compute Chain](diagrams/Compute_chain.draw.io.svg)
If this is unfamilar, a demo/simulation in [`scripts/ans.py`](../../scripts/ans.py) shows the full algorithm at work.

## system of equations/variables

signals

| var | meaning |
|---|---|
| x(n) | reference signal, the ambient noise picked up by the reference mic, before cancellation |
| y(n) | adaptive filter output, the anti-noise signal generated by W(z), sent to the mixer |
| d(n) | primary noise, the ambient noise as it actually arrives at the error mic (after room/ear acoustics) |
| y_s(n) | anti-noise after the real secondary path, y(n) as it arrives at the error mic |
| e(n) | error signal, residual noise at the error mic, e(n) = d(n) - y_s(n), used only to adapt the weights |
| x_f(n) | filtered reference, x(n) passed through the secondary path estimate S_hat(z), used in the weight update |

system blocks / filters

| var | meaning |
|---|---|
| W(z) | adaptive filter, holds the tap weights that shape x(n) into y(n) |
| w(n) | vector of adaptive filter tap weights at time n (the state W(z) updates each sample) |
| w(n+1) | updated tap weights after the LMS update rule is applied |
| S(z) | actual secondary path, everything physical between the dsp output and the error mic (dac, amp, speaker, air, mic, adc) |
| S_hat(z) | secondary path estimate, a modeled copy of S(z), used to pre-filter the reference so the adaptation direction is correct |

parameters

| var | meaning |
|---|---|
| mu | step size / learning rate, controls how fast the weights adapt, too high causes instability, too low causes slow convergence |
